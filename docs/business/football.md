# 足球业务指导

> 层级：项目。本文件维护足球观察台的使用目标、默认展示、判断含义、资料边界和验收依据。共同规则见根 [AGENTS.md](../../AGENTS.md)；现行筛选参数、数据来源和接口仍以 [足球配置](../../config/football.json)、[模块合同](../../config/module-contract.json) 及足球后端实现为准。

## 1. 用户要什么

足球观察台是钧钧自用的赛前观察清单。目标不是浏览全量赛程或生成投注结论，而是进入后直接认出：哪些比赛适用半破，哪些适用 75 分钟后观察，以及每条保留结果具体依据了哪些事实。

钧钧负责临场盘口、比分、水位和最终交易取舍。系统负责赛程、公开事实、历史样本、赛前筛选、中文表达和资料缺口；赛前保留不等于现在交易。

## 2. 怎样使用

打开足球观察台，先看默认候选，再按半破或 75 分钟后切换。默认候选是两种玩法中至少一种结论为 `keep` 的比赛并集，同一场只占一行；两种玩法都保留时并列展示，不据此自动排序。

需要核对时展开同一场，查看完整理由、来源、时间、其他玩法结论和资料缺口；也可进入“核对全部”查看 `pending`、`exclude`、`outside` 的比赛及原因。展开、搜索、切换玩法或查看详情后返回，清单仍保持可操作。

临场时由钧钧自己复核盘口和比赛进程；系统不把赛前清单延伸成自动下注或实时判断。

## 3. 先展示什么

每场主清单先显示中文对阵、北京时间、适用玩法，以及每个保留玩法的一条简短、具体、来自当前玩法的事实理由。半破与 75 分钟后分别说明理由；同场双玩法不人工添加优先级。

半破理由要能区分圈池依据、上半场历史支撑和已核实阵容等影响；75 分钟后理由要说明圈池条件与晚段历史依据。展开后再显示两三条关键事实、完整来源、其他玩法结果和具体缺项。

页面整体显示覆盖范围、最近成功更新时间和资料完整度。没有可靠来源时保持待补或读取不完整，不把空白页面说成“今天没有符合比赛”。

## 4. 怎样判断

两种玩法分别计算，不互相顶替。

- `keep`：关键赛前条件已满足，可以进入默认观察清单。辅助样本缺失时仍按现行规则保留，但必须显示缺项。
- `pending`：关键判定资料不足，不能推断为保留或排除，只进入全部核对。
- `exclude`：已有明确事实触发排除条件；显示首个触发层及对应事实。
- `outside`：不在当前圈池或研究范围；不能进入默认清单，但可查看原因。

初盘入池与历史支撑不是同一层事实。半破不能用初盘条件代替上半场历史依据；75 分钟后不能用球队关注名单代替晚段历史样本。来源暂缺不等于零样本，零样本也不自动推断“不会进球”。来源失败时保留上次有效结果和时间，并明确本轮不完整。

具体阈值、球队名单、时间窗口和字段由正式配置与后端实现维护。历史 PRD/SSD 只帮助追溯，不再定义另一套现行规则。

## 5. 资料和能力边界

- 系统只读取公开赛程和可核实历史事实；可靠实时赔率、临场水位及滚球资料由钧钧另行核验。
- 比赛身份不明确时不合并不同比赛；延期、改名和来源切换应保留原场关联，不制造重复。
- 关键资料缺失时显示待补；辅助资料缺失时显示具体缺项，同时保留已满足的赛前结论。
- 来源覆盖、晚段历史与完整端到端体验仍未闭合，不能把当前部分可用写成完整实时工作台。
- 足球业务的管理、判断和建议不替钧钧决定交易，也不从其他品种入口补成不存在的足球能力。

当前实现入口位于 `xiaoxue_api/modules/external/football/` 和 `src/modules/football/`，统一从 [技术导航](../architecture/PROJECT-MAP.md) 定位。

## 6. 怎样验收

| 场景 | 用户应看到的结果 |
|---|---|
| 仅半破保留 | 默认清单出现一次，只把半破作为适用玩法呈现，并给出具体事实理由 |
| 仅 75 分钟后保留 | 默认清单出现一次，显示晚段依据和对应来源 |
| 两种玩法都保留 | 同场一张卡，分别说明两种玩法，不自动加优先级 |
| 无任何玩法保留 | 不混进默认清单，可从“核对全部”查看排除或超出范围原因 |
| 有支撑样本 | 卡片直接解释关注依据，详情事实、数字、来源和时间一致 |
| 辅助样本缺失 | 如实显示缺项，仍按现行规则处理，不生成虚构支撑 |
| 关键资料缺失 | 显示 `pending`，不伪装成保留或没有符合比赛 |
| 来源失败 | 显示读取不完整；有上次有效结果时保留并标时间 |
| 展开并切换玩法 | 主清单仍可操作，同场不重复，桌面和窄屏均可阅读 |

验收必须经过真实页面的数据与用户可见结果。接口返回成功、单元测试通过或页签存在，只证明覆盖到的局部条件。
